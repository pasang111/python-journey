                                         Common error message in Python

When writing Python code, it's common to run into errors. Understanding these errors is key to debugging your code quickly and efficiently. These messages tell you exactly what went wrong, if you know how to read them.

Common Python errors include SyntaxError, NameError, TypeError, IndexError, and AttributeError. These occur when Python doesn't understand your code, or when your logic doesn't match the data you're working with.

example of SyntaxError :

print("Hello, world!"
# SyntaxError: unexpected EOF while parsing

example of NameError!:

print(name)
# NameError: name 'name' is not defined
You're trying to print a variable that hasn't been defined yet. Python raises a NameError when it can't find a variable by that name.

example of a TypeError:

5 + "5"
# TypeError: unsupported operand type(s) for +: 'int' and 'str'
You can't add an integer and a string together. Python raises a TypeError when you try to perform an operation on incompatible data types.

example of indexerror!!
my_list = [1, 2, 3]
print(my_list[5])
# IndexError: list index out of range
Python lists start indexing from 0. So a list with 3 items has indexes 0, 1, 2. Trying to access index 3 or higher causes an IndexError.

example of Attributeerror!
num = 42
num.append(5)
# AttributeError: 'int' object has no attribute 'append'
# .append() is a method used with lists.
# An int does not have an append() method.


                                                Python Error Handling
Python uses exception handling to prevent a program from crashing when an error occurs.

Main keyword

1. try

try = 
    result = 10/0

2. except

handles the error if occcurs

except ZeroDivisionError:
    print("Cannot divide by zero")

IMPORTANT: ZeroDivisionError is and exeption class..

3. else 

Runs only when no error occurs

try:
     result = 10\0
except ZeroDivisionError:
    print("Error)
else:
    print("Success")

4. finally

Runs whether an error occcurs or not

try:
    result = 10/0
except ZeroDivisionError:
    print("Error")
finally:
    print("This always runs")


5. raise

Used to manually create an exception

for eg:

age = -1

if age < 0:
    raise ValueError("Age cannot be negative")

6. as - Storing the error

we can store exception in a variable

try:
    result = 10/0
except ZeroDivisionError as e:
    print(e)

here :
ZeroDivisionError = exception class
e = variable containing the exception


The main IMPORTANT parts of python exception handling are:

try, except, else, finally and raise

try:
    # code that might cause an error
except SomeError:
    # handle the error
else:
    # runs if there is no error
finally:
    # always runs
